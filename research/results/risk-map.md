# risk-map: every choice on the menu, three windows

Card: `cards/risk-map.md`. Six live assets, dividend-adjusted prices, the gym's costs, decided each Friday. One backtest per variant from 1994-02-01 to 2025-11-09; the later windows are slices of the same account, with the worst drop and the time below a high counted from the window's first day. Built by `lib/risk_map.py`.

Names: `hold` always holds; `tsmom12` holds a slot only when the asset is up over a year; `tv60`, `tv40`, `tv20` add a cap on each slot's volatility (60%, 40%, 20% a year). `c00`, `c05`, `c10`: 0%, 5%, 10% in each coin; `c17`: equal slots (a sixth each once all six assets exist).
