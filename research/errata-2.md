## What does not change

No decision SUMMARY asks for changes (review-2, verdict). The gates checked stay dead. A gate
passes only if the true t clears 2 with the predicted sign and also ranks near the top of its
placebos; removing look-ahead placebos can only narrow the null, so it could flip a verdict only
where the true t passed by itself and the rank alone failed. Every gate re-read so far failed on
its own t (wrong sign or |t| < 2), so no verdict flips; the list is in `research/gate-null.md`
on `gate-null-2`. Where a null is widened instead (stricter placebos), passing only gets harder.
