# breadth-screen: weekly within-class rank IC, 34 ETFs (train, Fridays to 2025-11)

Card `cards/breadth-screen.md`; script `lib/breadth_screen.py` (signals, IC and
bootstrap from `lib/multisignal_ic.py`). Descriptive screen, no backtest. Weekly IC =
mean over the classes with >= 3 ETFs that week of the within-class Spearman IC.
Bootstrap: stationary, mean block 13 weeks, 5000 draws. Placebo A: scores
shuffled within class each week (2000 draws); placebo B: 2000 random
fixed relabels within class. Bar: 1 partial > 0 at 99.5% and month same sign;
2 placebos; 3 eras 3/4 and half the classes; 4a partial >= 0.10; 4b partial IC-IR
(mean / sd x sqrt 52) >= 0.59 (BAR.md far-rule edge at N 1,012).
